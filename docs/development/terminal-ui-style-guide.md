# peforth 終端 UI 風格規格

本文件整理終端介面的視覺與操作規則，供後續設計沿用。

## 命令提示與選取樣式

- 命令提示使用粗體草綠色 #87d787。
- 選取項目使用粗體深綠字（RGB 0,100,0）配白色背景。
- 未選取項目維持一般字重與終端預設字色。
- Tab completion 底部提示不反白，箭頭顯示為 ↑ ↓ ← →，箭頭之間留一格。

## AI approval

- approval 區塊前留一行空白。
- AI permission requested 保持原有的粗體草綠色樣式。
- Purpose 使用普通字重。
- Forth action 標籤保留原樣；proposal 使用普通字重與深綠色，不放入固定尺寸的 box。
- 四個選項使用普通字重；允許與信任選項維持草綠色，拒絕維持紅色，取消維持灰色。
- 方向鍵在實際選項間循環；Enter 或 Space 確認；數字鍵立即選擇對應項目。
- 操作時，選取列使用粗體深綠字配白底；不額外顯示目前選取項目的狀態行。

## Chat turn

- user 標示使用 👋；assistant 標示使用 🪄 peforth，名稱全小寫。
- Chat REPL、`ai:` 與 `AI:` 都保留終端中原始輸入，再顯示同文的裝飾 user turn；assistant 回覆使用相同 turn 樣式。
- 每則訊息以圓角上、下框線標示範圍；內容區不畫左右直線。
- 長訊息可自然折行；框線標示訊息的起點與終點。
